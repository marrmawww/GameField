Проект Game

Состав:
- Health.h, Armor.h, Attack.h — классы характеристик;
- Unit.h / Unit.cpp — абстрактный базовый юнит и общая логика;
- Infantry.h, Archer.h, Cavalry.h, Elf.h — четыре категории и восемь конкретных юнитов;
- UnitFactory.h / UnitFactory.cpp — фабричный метод и четыре фабрики;
- GameField.h / GameField.cpp — игровое поле;
- GameFieldIterator.h — собственный итератор;
- main.cpp — пять демонстрационных сценариев с поясняющими комментариями.

Обоснование выбора паттерна «Фабричный метод»
В проекте используется паттерн «Фабричный метод» (Factory Method). Абстрактный класс UnitFactory определяет общий интерфейс создания юнитов с помощью метода createUnit(...). Конкретные фабрики InfantryFactory, ArcherFactory, CavalryFactory и ElfFactory создают объекты соответствующих категорий. 
Паттерн выбран потому, что он отделяет создание объектов от игрового поля и основного сценария программы. GameField работает с общим базовым классом Unit и не зависит от конкретных конструкторов юнитов.
При добавлении новой категории можно создать новый класс юнита и соответствующую фабрику, не изменяя основной механизм хранения и обхода объектов в GameField.
Абстрактная фабрика не выбрана, поскольку проекту требуется создавать отдельные объекты разных типов, а не целые семейства взаимосвязанных объектов. Поэтому фабричный метод является более простым и подходящим решением.
